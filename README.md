# Мой первый итальянский

Интерактивная рабочая тетрадь для первого класса. Разработка приложения — Марина Воронцова.

## Публикация через GitHub Pages

Загрузите содержимое архива в корень ветки `main`. В разделе **Settings → Pages** выберите **Deploy from a branch**, затем `main` и `/ (root)` и нажмите **Save**.

Сайт не требует сборки. После первой загрузки материалы можно открыть без интернета через установленное приложение или тот же браузер. Ответы сохраняются локально. При переезде с другого адреса прежний прогресс автоматически не переносится.
